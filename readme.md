# 6-Week Product Development Roadmap

## Theme: Voice-First AI Applications
Participants are required to build an innovative product centered around voice interaction using Google’s Gemini 2.5 Flash Native Audio Dialog capabilities. The focus should be on creating seamless, intelligent, and real-time voice-driven experiences that solve meaningful real-world problems.

## Evaluation Criteria
Projects will be evaluated not only on technical execution and creativity, but also on their potential to evolve into scalable, startup-worthy solutions. Participants are encouraged to think beyond prototypes and design products with strong user value, practical applicability, and market relevance.
